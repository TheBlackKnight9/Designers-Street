# Release v0.7.0 — Phase 7 Social Commerce

**Date:** 2026-07-30  
**Git tags:** `v0.7.0`, `phase-7-complete`  
**Branch:** `feature/phase-7-social-commerce`  
**Previous baseline:** Phase 6 Production Foundation (`v0.6.0` / `phase-6-complete`)

---

## Overview

v0.7.0 delivers **Phase 7 Social Commerce** and **Phase 7 UX Polish** on top of the frozen Phase 6 buyer commerce foundation. Designer's Street now supports persistent social engagement (like, follow, comment, share, wishlist) and Instagram/TikTok Shop–style **shoppable reels** inside the existing Universal Media Viewer — without a second feed/reel system.

Final QA verdict: **READY FOR PHASE 8** (`docs/phase-7-final-qa.md`).

---

## New Features

### Social commerce
- Persistent likes on posts and products
- Follow / unfollow designers
- Comments with nested replies, edit/delete own
- Notifications for like, comment, reply, follow, order
- Feed sorts: recent · popular · trending · following
- Share (native + clipboard) and wishlist save

### Shoppable reels (Media Viewer continuous mode)
- Like, Comment, Share, Save, Follow in-viewer
- Floating glass product card (image, name, designer, price, rating, stock)
- Size + color selection before Add to Bag
- Add to Bag · Buy Now · View Product without leaving the reel
- Quick cart confirmation drawer (Continue Shopping / Checkout)
- Designer mini profile sheet (bio, followers, featured pieces)
- Trust chips (delivery, returns, authentic, limited)

### Demo content expansion
- Expanded designers, products, feed videos, stories, browse categories
- Seed preserves `videoUrl` / media for lookbook reels

---

## Architecture Changes

- Extended Phase 6 Like / Follow / Comment / Notification models (no parallel social stack)
- `resolveShoppableReel()` enriches viewer items from known product/post IDs only (does not invent commerce targets)
- Reel overlay components on Universal Media Viewer (`ReelChrome`, sheets, floating card)
- Client analytics façade buffers reel/commerce events (`trackMediaEvent`)
- Safe internal redirects (`safeInternalPath`) for post-login `next` params

## Database Changes

Migration: `prisma/migrations/20260730190000_phase7_social/`

- `posts.comments_count`
- `products.likes_count`
- `likes.product_id` (nullable `post_id`; unique per user+product)
- Notification targets: `post_id`, `product_id`, `designer_id`, `actor_user_id`
- Indexes on likes / comments for social queries

Preserve Prisma migrations under `prisma/migrations/` as the schema baseline before Phase 8.

## API Changes

| Endpoint | Purpose |
|----------|---------|
| `POST /api/posts/[id]/like` | Toggle post like |
| `GET/POST /api/posts/[id]/comments` | List / create comments |
| `PATCH/DELETE /api/comments/[id]` | Edit / delete own comment |
| `POST /api/products/[id]/like` | Toggle product like |
| `POST /api/designers/[id]/follow` | Toggle follow |
| `GET /api/notifications` | Buyer notification feed |
| `PATCH /api/notifications/[id]` | Mark read |

Feed supports engagement sorts; public rate limits apply on mutate routes.

## Performance Improvements

- Blur poster → fade-in video playback
- Preload next 2–3 reel videos
- Feed infinite scroll: in-flight lock + ID dedupe
- Adjacent media prefetch in viewer queue

---

## Bug Fixes (Final QA)

- Removed inventing wrong product/post IDs for shoppable chrome
- Size-aware In Bag / Add to Bag / Buy Now
- Cart optimistic add rolls back on remote API failure
- Quick cart link `/bag` → `/cart`
- Feed pagination race / invalid cursor restart
- Social errors no longer always “Sign in”
- Auth `next` open-redirect hardened
- Buyer routes gated when Supabase unset
- Share clipboard failure handled
- Guest `ds-cart` merged on login
- TopBar badge hydration deferred

---

## Known Limitations

- Color selected in reel is UI-only (not stored on `CartItem`)
- Designer mini-sheet still mock-backed in API mode
- Emoji reactions are client-local (not persisted)
- Checkout payment remains a placeholder (by design since Phase 6)
- Unknown category slugs use soft empty state vs hard 404

None block Phase 8.
