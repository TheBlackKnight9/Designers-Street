## 🌟 Highlights & New Features

1. **Named Fit Profiles & Measurement Versions** (`MeasurementProfile`):
   - Buyers can save multiple fit profiles (e.g. *Bridal Fit '26*, *Winter Gala Suit*) with chest, waist, hip, shoulder, sleeve, inseam, height, and neck measurements.

2. **Published Consultation Slots** (`AppointmentSlot`):
   - Designer houses publish available consultation slots with date, time, and type (`virtual`, `studio_visit`, `phone`).

3. **Bespoke Conversation Thread** (`BespokeMessage`):
   - Real-time interaction history between buyers and atelier master weavers on custom garment orders.

4. **Multi-Type File Attachments** (`BespokeAttachment`):
   - Support for inspiration images, sketches, fabric swatches, and fit documents.

5. **Personal Atelier Portals**:
   - Customer Portal: `/account/atelier`
   - Designer House Portal: `/dashboard/atelier`
   - Appointment Booking: `/appointments/book`
   - Custom Garment Spec Submission: `/bespoke/request`
