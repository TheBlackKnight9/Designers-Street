# Release v0.8.1 — Foundation Stabilization

**Date:** 2026-07-31  
**Baseline:** v0.8.0 Luxury Marketplace

## Summary

v0.8.1 is a non-feature stabilization release. It preserves the marketplace UI while
restoring repository → service → API persistence boundaries, isolating legacy catalog
state, restoring browser zoom, documenting deferred workflows, and aligning package
metadata with the release line.

## No product scope changes

No Phase 9 work, editorial redesign, appointment implementation, bespoke submission,
CRM, AI, or marketing functionality is included.
