## 🌟 Highlights & Enhancements

1. **Production-Grade Checkout Engine (`/api/checkout`)**:
   - Dedicated `/api/checkout` API route for order creation.
   - Database price locking recalculates subtotal and total from database `Product` price records.
   - Transactional stock reservation and decrement for `piecesRemaining` and `editionSold`.

2. **Immutable Order Snapshots & History**:
   - Captures product metadata, variant size, price, and shipping address snapshot into `Order` and `OrderItem` records.
   - Full order listing (`/api/orders`) and single order view (`/api/orders/[id]`).

3. **Cart & Address Stabilization**:
   - Guest cart to user cart migration upon authentication.
   - Address ownership verification and default address rule enforcement.

4. **Zero-Regression Architecture**:
   - Protected Instagram-style Reels, Feed, Stories, and Atelier services.
