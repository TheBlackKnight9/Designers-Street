# Release Notes — Designer's Street v0.9.0

**Release Date:** July 31, 2026  
**Phase:** Phase 9 — Editorial & Discovery Experience  
**Status:** Production Ready  

---

## What's New in v0.9.0

### 📰 SSENSE & Farfetch Style Editorial Magazine Homepage
* **Hero Cover Story**: Immersive video/image campaign hero (`HeroCampaignBanner`) with direct launch into `MediaViewer`.
* **Designer Spotlight**: Highlighted atelier house with designer philosophy quote and signature product shelf.
* **Curated Collections**: Themed seasonal edits (e.g. *"Royal Heritage Lehengas"*, *"Cocktail Drapes & Modern Sari Edit"*) with curator notes.
* **Magazine Feature Stories**: Long-form article reader (`/editorial/[slug]`) with rich text, pull quotes, craft photos, and inline shoppable products.

### 🗄️ Database & Schema Extensions (`prisma/schema.prisma`)
* **Prisma Models**: Added `EditorialCampaign`, `EditorialCollection`, `EditorialCollectionItem`, `EditorialArticle`, and `FeaturedSection`.
* **Dynamic Section Control**: `FeaturedSection` model drives homepage section ordering dynamically without code edits.

### ⚙️ CMS / Admin Dashboard Integration
* **Editorial CMS Tab**: Added to `/admin` dashboard for creating and managing campaigns, collections, articles, and home section layout.
* **Admin REST Endpoints**: `/api/dashboard/editorial/campaigns`, `/api/dashboard/editorial/collections`, `/api/dashboard/editorial/articles`, `/api/dashboard/editorial/sections`.

### 🛣️ RESTful Routing
* Updated collection route to plural `/collections/[slug]` matching `/api/editorial/collections`.

---

## Architectural Invariants Maintained
- `Prisma/PostgreSQL → Repository → Service → API Route Handler → Hooks → UI`
- Universal `MediaViewer` reuse for video campaigns.
- Dual-mode fallback (`USE_DATABASE=false` with `src/lib/phase9-demo.ts`).
