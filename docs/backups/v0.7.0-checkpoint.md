# v0.7.0 Backup Checkpoint

Create these backups **before** Phase 8 work begins.

## Checklist

- [ ] Export live database schema (Supabase SQL editor or `pg_dump --schema-only`)
- [ ] Keep a copy of current seed data (`prisma/seed.ts` + `src/lib/mock-data.ts` / `demo-expand.ts`)
- [ ] Preserve Prisma migrations folder (`prisma/migrations/`) — do not rewrite history
- [ ] Treat expanded demo catalog as baseline content for regression compares
- [ ] Git tags `v0.7.0` and `phase-7-complete` on `feature/phase-7-social-commerce`

## Suggested export commands

```bash
# Schema-only dump (adjust connection string)
pg_dump "$DATABASE_URL" --schema-only -f docs/backups/v0.7.0-schema.sql

# Optional data dump for critical tables
pg_dump "$DATABASE_URL" --data-only -t products -t posts -t likes -t comments -t follows -f docs/backups/v0.7.0-social-data.sql
```

Store dumps outside the working tree or commit only schema dumps if they contain no secrets.

## Rollback

```bash
git checkout v0.7.0
# or
git checkout phase-7-complete
```

Then restore DB from the schema/data dumps if needed and re-run `prisma migrate deploy` to the Phase 7 migration set.
